# SaaS Landing Page

A modern, responsive **SaaS landing page** built with **React, Vite, and Tailwind CSS**.
This project is part of my developer portfolio and showcases my ability to design and build clean, fast, and responsive user interfaces.

## ✨ Features

* Fully responsive design across devices
* Clean and modern UI
* Smooth animations with **Framer Motion**
* Landing page sections: Hero, Features, Pricing, and Contact
* Reusable components and organized code structure

## 🚀 Getting Started

### Prerequisites

* [Node.js](https://nodejs.org/) (v14 or higher)
* npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/saas-landing-page.git
   ```
2. Navigate into the project folder:

   ```bash
   cd saas-landing-page
   ```
3. Install dependencies:

   ```bash
   npm install
   ```
4. Start the development server:

   ```bash
   npm run dev
   ```
5. Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
```

## 🛠️ Customization

* Update text and branding in the components (e.g., Hero, Features, Pricing).
* Replace images in `/public/assets/images/`.
* Adjust colors and theme in `tailwind.config.js`.
